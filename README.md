# 🇬🇧 EnglishSpace — Інтернет-магазин курсів англійської мови

## 📖 Про проект
[cite_start]**EnglishSpace** — це навчальний веб-проект, створений в рамках розрахункової роботи з курсу "Управління ІТ-проектами"[cite: 1]. Це адаптивна платформа для демонстрації та продажу онлайн-курсів англійської мови, розроблена з акцентом на зручний користувацький інтерфейс (UI/UX) та сучасні веб-стандарти.

## ✨ Основний функціонал
* **Сучасний дизайн:** Використання CSS-анімацій, градієнтів та hover-ефектів для "живого" інтерфейсу.
* **Адаптивність (Responsive Design):** Сайт коректно відображається на будь-яких пристроях (смартфони, планшети, ПК) завдяки використанню технологій Flexbox та CSS Grid.
* **Динамічний кошик:** Передача даних про обраний курс (назва та ціна) до кошика оформлення замовлення реалізована за допомогою JavaScript (URL Search Params) без використання бази даних.
* **Кабінет студента:** Імітація особистого профілю з відстеженням прогресу навчання та системою досягнень.

## 🛠 Технології
* **HTML5:** Семантична розмітка сторінок.
* **CSS3:** Стилізація, плавні анімації, медіа-запити для мобільних пристроїв.
* **JavaScript (Vanilla):** Логіка динамічного підтягування контенту.
* **FontAwesome 6.0:** Векторні іконки.
